# 刚体接触后端技术路线

用户在同一场景中用 `method` 选择接触几何，用 `solver` 选择接触响应，用 `device` 选择执行设备。冻结的 CPU 实现提供迁移的对照。当前动力学算例通过离散接触的侵入深度计算载荷。

## 开发分支的全 GPU 路径

承载区积分在有效列上累加十个双精度分量，随后重建形心、法向、压入深度和分布力矩。保序实现按原列序压紧索引，并行生成各列贡献，再让十个线程分别累加各自的分量。`--region-reduction serial` 提供原顺序的单线程对照，`audit` 在同一试算姿态、同一区域上检查全部累加结果和世界坐标系下两刚体各自的三轴力矩。`warp` 与 `audit-warp` 保留改变加法顺序的树形归约，用于数值消融。[设备端累加](../src/cuda_resident_geometry.cuh) · [同姿态力矩核验](../src/cuda_resident_step.cuh) · [减速器实验](../results/aes/cuda-region-reduction/README.md)

通用网格几何入口 `IntersectionBatch` 按物体对读取当前的三维刚体相对变换。每对独立使用局部 AABB 树，候选队列和相交结果留在设备上。几何级验证逐步回放完整五秒的减速器姿态。另外用非平行坐标系、交换物体顺序和接触后分离检验三维变换。输出为相交三角片的原始编号，可进一步构造交点、交线和共面多边形。运行完整网格动力学还需要将这些几何结果转换成连续的承载区、接触深度和力矩，再反馈给积分器。[GPU 网格接口](../nurbscontact_gpu/bvh.py) · [原始测量和验收范围](../results/aes/gpu-mesh-geometry/README.md) · [三维回归](../tests/test_gpu_triangle_intersection.py)

`cad-compiled --device cuda-resident` 从 `.ncpart` 加载参数曲面与裁剪边界。准备阶段生成固定方位下的局部包围盒、常用积分阶数的材料点和时间推进所需的 CUDA Graph。在线提交一次图，GPU 按当前刚体姿态查询可能接触的面，在参数域确认承载点，按连通区积分，并将合力和力矩交给隐式积分器。坐标、牛顿试算、线搜索与重试都保存在显存中。终止后集中回传轨迹和诊断。

候选面的复用受相对刚体运动上界约束。多个线程并行尝试同一对面的不同起点，再按原始优先顺序选取见证点。旧连通路径上的每段都需要在新姿态重新检查。设备无法判定几何、超出工作区容量或用尽积分重试时，调用方收到错误。当前动力学入口支持转动和移动坐标、共享坐标的多级传动、无摩擦罚力、预测姿态更新和谱半径为零的广义 α 积分。

编译时打开 `NC_WITH_CUDA_COLUMNS`。运行参数和五秒减速器的比较命令见 [README](../README.md#precompiled-cad-on-cuda)。使用 `nc_compiled_tests --cuda` 检验接触加载与释放，使用 `nc_compiled_tests --audit-parts <part.ncpart> ...` 检查设备端点位、法向和裁剪分类。接触搜索、区域积分和时间推进分别见 [GPU 几何](../src/cuda_resident_geometry.cuh) 与 [GPU 积分器](../src/cuda_resident_step.cuh)。

## CPU 先完成什么

1. **固定姿态下找全承载区。** 在同一预测姿态，对物体对做 BVH 粗筛，以带裁剪边界的曲面块对为候选。在已有离散搜索的基础上，为采样点之间、裁剪边界附近和新进入接触的曲面建立补搜路径。分离条件可核验时整块排除，其余候选局部细分并在实际 CAD 曲面上求解。上一姿态的面和参数只用作初值或有位移余量的候选缓存。保留冷启动搜索，复用时检查覆盖范围，积分步被拒绝时重新验证缓存。运行时仅用预编译几何；预算耗尽的候选返回未解状态，不能作为分离或零载荷。
2. **让精算取决于合力和力矩的误差。** 几何层给出接触区域及其几何范围；给定力定律和当前状态，由求力层估计所有未决块合计可能改变多少合力及绕指定参考点的力矩。优先细分贡献上界大的块。当前共享刚度按承载区数量分摊，新出现的小区会改变已发现区域的载荷。首版采用保守规则：只要区域数仍可能改变，就继续查清，再按载荷预算停止积分。上界需要覆盖剩余候选与积分误差；只有经验误差估计时，应按估计标记。若另行研究按面积分配载荷，在网格和 CAD 两边一起切换力律，单独比较。
3. **接回现有动力学入口。** 沿用 `PairRegionQuery` 和 `ContactRegion` 交给当前 HHT 罚力路径。批量接口按物体对接收位姿，输出区域范围、标识、世界坐标接触点、A 指向 B 的单位法向、侵入深度及分布载荷的附加力臂。明确长度、坐标系和力矩参考点。查询状态区分分离、已解析接触和未解。几何结果与求解器共享，罚法生成力与力矩，乘子、增广乘子、SAP、LCP、NCP 和 SOCCP 可经各自适配层构造约束或冲量。第一轮五秒对比固定罚法；已有的其他求解器按各自积分和物理模型另验。[现有几何接口](../include/nurbscontact/contact_dynamics.hpp) · [共享刚度实现](../src/contact_dynamics.cpp) · [冲量求解接口](../include/nurbscontact/surface_impulse.hpp)

## CPU 实现与验收记录

固定的运行对照为 `mesh-obb` 加 `contour-ray` 和 `cad-compiled`。候选方法 `cad-boundary` 使用同一场景、共享罚刚度和 HHT。它从 `.ncpart` 加载几何，在初始化时沿裁剪边和矩形参数域的边界增加搜索起点。在线阶段用双向 BVH、实际曲面的材料出射点及连通区求力。搜索密度有限。加载时构造的索引和初始化耗时单列。

| 选项 | 做法 | 验证范围 |
| --- | --- | --- |
| `--method cad-boundary` | 用边界附近的额外起点补搜窄承载区，沿用原有区域积分 | 两级减速器 25 个同姿态查询的区域数全部与独立 STEP 对照一致，五秒闭环已完成。凸轮响应对普通积分精度敏感。 |
| 追加 `--cubature fixed96` | 每个面的两个参数方向各划 96 格做积分。已发现的区域若没有有效积分弦，就在见证点附近按同一分辨率对材料区间积分 | 凸轮 3.2 秒、0.1 ms 步长，71 次切换均可配对。从动件位移 RMS 误差为 13.45 µm。减速器 25 个同姿态的轴力矩最大差 3.62 N·m。 |
| 追加 `--cubature adaptive --force-tol-n 10 --moment-tol-nm 0.5` | 比较相邻积分阶数的合力及绕两个物体原点的力矩，达到设定阈值时停止 | 实验选项，适用于无摩擦的纯弹性罚力。阈值衡量积分估计的变化。观察到见证点历史对结果有影响，曾在 30 min 上限内仅推进减速器 2.507 秒。 |

25 个减速器姿态中含 12 个追加留出的姿态。凸轮有独立运动方程核对。减速器以原 STEP 实体相交给出同姿态几何和载荷参考，再以 RecurDyn 作整机交叉核对。固定 96 格模式在减速器上达到 30 min 进程上限时完成 1.0063 s；主要开销是已发现承载区的积分。原始记录、响应曲线及命令见[本轮 CPU 验收记录](../results/aes/cpu-bezier/boundary/README.md)。

## GPU 后端的接口与验收

冻结的 CPU 时程提供移植对照。开发分支已接通设备常驻的罚力与隐式积分，下表还列出对外交换载荷时的计时要求。

| 接口边界 | GPU 迁移方案 |
| --- | --- |
| 离线资产 | 沿用相同的零件文件及版本标识。加载时把控制点、权重、裁剪环、拓扑邻接和 BVH 展开为连续数组，以索引和偏移量关联。允许设备专用布局，保留面、边、物体对的逻辑标识。资产只依赖零件几何。 |
| 在线阶段 | 几何、位姿、候选队列、区域与积分状态常驻显存。设备内依次完成物体对/曲面块筛选、裁剪与局部细分、区域归并、分区积分和按物体归约，再执行求力与时间积分。并行单位是同一试算中的物体对、曲面块和积分块。队列满时分批继续或报告未解。 |
| 数值与通信 | CPU 双精度给出逐姿态参考，首个 GPU 版本采用双精度核对分离判定、载荷与力矩。CPU 和 GPU 按相同误差容差验收。主机负责初始化及所需的外部载荷交换和结果输出。热路径的曲面求交、重试和求解留在设备上。 |
| 实时验收 | 先比同姿态接触区和合力矩，再比五秒闭环。0.1 ms 主步对应 100 µs 期限。分别测全设备运行及逐步同步交换载荷两种模式，包含各自所需同步；报告 50,000 步总耗时、P99、最大单步耗时与超时步比例。五秒物理时间在五秒墙钟内完成衡量总吞吐，零超时步检验本次运行的逐步实时性。 |

已有 GPU 包面向固定平行转轴，使用网格及预计算的载荷或材料点映射。可复用其中的设备常驻与载荷交换经验。新 CAD 路径按当前姿态从零件几何求载荷，需单独验收。[现有 GPU 后端范围](../nurbscontact_gpu/README.md)
