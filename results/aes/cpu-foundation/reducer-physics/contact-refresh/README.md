## 哪两项修改改变了整段响应

1. 每次隐式迭代都在新姿态下更新原有承载点。原算法遇到空的预测接触集时，会把零载荷沿用到步末。修正版在预测点全部或部分脱开时重查实际三角面，并将新载荷和切线刚度送回当前迭代。整对接触的共享刚度按实际正载荷点数分配。逐一重查 0.1 ms 修正版的全部零载荷输出步，第一级 2 步、第二级 8 步均无正压入。旧版分别有 882 和 278 个零载荷步在同姿态下有正压入。[旧版回放](../zero-load-replay.json) · [修正版回放](zero-load-replay.json)
2. 同网格 RecurDyn 的 `case.log` 记录了高频谱半径 0、质量权重 −1、力权重 0、β = 1、γ = 1.5。旧 CPU 采用 α = −0.1 的 HHT。现在可通过 `--spectral-radius 0` 选用对应的广义 α 系数。各程序仍各自处理内部步长与收敛。结果表的前两次 CPU 对照沿用相同 HHT，可以单独看到接触修正的收益。材料阻尼和摩擦均保持为零。解析双球碰撞在 5 s 仿真中给出的峰力为 22.4985 N、冲量为 0.449995 N·s，解析值分别为 22.5 N、0.45 N·s。[解析算例](sphere.json) · [商业模型和日志归档](../native-decks.zip)

保留旧 HHT、只修接触时，第一级有 82 个零载荷输出步，第二级有 592 个。在各自已接受的实际姿态逐步重新检测，全部得到零压入。这一对照独立验证了漏载修复。[原 HHT 的修正后回放](zero-load-hht.json)

## 峰值差在哪里

全程五个一秒区间分别取 RecurDyn 输出轴扭矩最大时刻。将 CPU 网格检测放到这五个商业模型姿态上，第二级每次都有三处正压入，商业接触文件每次报告两处正载荷。用闭合网格的立体角绕数独立检验，每次多出的一点均位于两个实体内部。沿该点法向分别与两侧三角面求交，总压入为 5.05–16.03 μm。两个模型对实际存在的局部重叠给出了不同的承载分配。[五个峰时的逐点核验](support-counts-full.json)

例如在 4.6315 s，RecurDyn 的输出扭矩为 241.10 N·m。相同轴姿态下 CPU 算得 178.85 N·m，CPU 自己积分到这一时刻为 158.18 N·m。固定姿态的约 62.25 N·m 差异已包含接触点数、位置、深度和共享刚度分配的影响，独立积分后的姿态变化进一步改变了载荷。在全程每 5 ms 区间内随机取一帧，共 1,000 帧。第二级有 317 帧的正载荷点数不同，这些帧的同姿态扭矩 RMS 差为 37.78 N·m，点数相同的 683 帧为 11.76 N·m。附加选取的五个峰时单列，未额外计入抽样统计。[全程姿态回放](support-counts-full.json) · [制动段逐帧复核](support-counts.json)

另在 CPU 自己接受的轨迹上，每隔 100 个输出步从两侧三角面重新搜索承载区。501 个姿态均成功返回，重新计算的输出轴扭矩与积分实际使用值的 RMS 差为 1.40 N·m。这项检查与商业姿态上的 23.38 N·m 差异分别衡量步内接触点复用和不同接触模型的影响。[步末几何重算](zero-load-replay.json)

0.1 ms 修正版在最后一秒的扭矩标准差为 12.30 N·m，RecurDyn 为 27.48 N·m。将 CPU 步长减半后，全程峰值更接近商业结果，同时全程逐点 RMS 差增至 32.70 N·m。现有证据支持漏载修复与轴速响应改善，齿面瞬态强度评价还需要独立的载荷验证。

## 计算代价与复现

候选三角面可以跨姿态复用。散列表用于寻找可能可用的旧姿态，只有两次相对变换给出的最大刚体位移在原搜索余量内，才复用候选面编号。每个姿态均重新计算有效交面、法向、深度和力。每个物体对最多保留 64 MiB 的压缩候选编号，索引及其它几何存储另计。0.1 ms 修正版观测到的进程峰值工作集约 248 MiB。相同积分设置下，对照有无该候选缓存的前 5,674 个共同输出状态，三轴角度、转速逐值一致。只修接触的 HHT 对照中，前 41,428 个共同状态也逐值一致。[内存记录](memory-100us.json) · [未缓存控制运行的 30 min 截止记录](uncached-timeout.json)

0.1 ms 修正版两次完整进程分别用时 652.44 s、756.95 s，50,001 行原始响应的 SHA-256 完全相同，只修接触的 HHT 用时 254.99 s，0.05 ms 复算用时 322.24 s。同网格 RecurDyn 的已归档完整进程耗时 1,705.19 s。计时包含各自进程的加载和输出，受机器负载影响。[主运行](cpu-100us.json) · [重复运行](cpu-100us-repeat.json) · [HHT 对照](contact-only-hht.json) · [步长减半](cpu-50us.json)
