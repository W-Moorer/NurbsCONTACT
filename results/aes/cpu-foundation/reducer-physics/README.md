# 两级减速器的接触载荷与 GPU 验证

CPU 与 RecurDyn 各自从初态积分 5 s。主步长与输出间隔均为 0.1 ms，RecurDyn 可以取较小内部步。两个模型共用四份 Gmsh 三角面、轴惯量、初态、轴承参数、驱动力矩和制动力矩。四轮分别有 10,216、10,240、27,934、17,342 片。另保留原商业模型的 20,636 片结果作为独立一列。替换商业模型网格时，将三角面法向赋给该面三个角点。

## 误差来源与已做的修改

1. **同一处接触曾重复计力。** 同姿态用轴角和四元数输入，修复前第一级得到 1,817.71 和 2,422.43 N。现在用相连共面支撑和有限公共棱线定位力臂。两种表示、两种刚体输入顺序均找到同样的两处承载，合力与关于原点的合力矩一致。[原始对照](separate-supports.json) · [交换刚体与姿态表示](line-support-body-order.json)
2. **接触点数曾改变整对齿轮的刚度。** 以实际导出的逐点法向、压入量、位置和载荷重建合力。在此原始 RecurDyn 模型的制动窗口内，对正载荷点直接相加，第二级轴矩 RMS 差为 337.69 N·m。按正载荷点数取均值，差为 0.00000637 N·m。CPU 提供整对共用罚刚度的选项。这里核对的是这份具体输入文件的行为。[原网格逐点重建](native-point-laws.json) · [同网格重建](matched-point-laws.json) · [逐点输出](point-exports.zip)
3. **同一姿态的剩余力矩差对取点和法向敏感。** 在相同 Gmsh 三角片的 121 个制动姿态，使用每处最深点并分别施加整份刚度，第二级扭矩 RMS 差为 514.90 N·m。共享刚度后为 59.22 N·m。改为依据三角交线选取局部位置，沿接触法向分别求与两个实际面的交点，降至 29.95 N·m。对于连续线支撑保留有限棱特征。手工给定商业软件报告的点和法向时，第一级 223 个、第二级 315 个承载点的几何深度 RMS 差仅为 0.0090 和 0.0071 µm。力仍需依赖自主选点。[固定姿态曲线](fixed-poses.png) · [各阶段重算](contour-replay.json) · [给定点与法向的几何核对](normal-ray-check.json)
4. **HHT 试算中的接触更新。** 每个新步先确定接触区，在该次 Newton 迭代内用两侧材料点随体运动更新间隙，细分时重新检测。每次 Newton 试算重选区域的版本在 0.015 s 附近未收敛。长跑输入将 CPU 的过深拒绝阈值从 53 调至 200 µm，罚刚度保持 160,000 N/mm。独立的双球正碰在 5 s 得到峰值 22.49934 N、法向冲量 0.449995 N·s，解析值为 22.5 N 和 0.45 N·s。[逐次重选记录](newton-contour-run.json) · [解析碰撞](analytic-impact.json)

## 哪些尖峰可以解释

**三角片上沿一个方向量出的长度取决于方向。** 同网格商业模型第二级有 96 帧合力超过 100 kN，原商业网格在 5 s 内的最大值为 8.014 kN。前 0.13 s 导出了所有接触点。其中四帧，商业模型报告一个沿轴向的正载荷点。以 0.0759 s 为例，沿该法向两侧各量到约 4.641 mm，合计 9.2823 mm，逐点力为 1.485 MN。该点对输出轴的直接扭矩为零。该点位于第一个闭合网格内部、第二个外部，到两侧最近表面各约 1.61、1.64 mm。对全程 96 个姿态逐一把两齿轮中心距增加 100 µm，所有三角面交点均消失，两个连通实体也互不包含。这给刚体最小分离平移提供了 100 µm 的实测上界。9.28 mm 描述特定轴向截距，将其用作齿面真实压入量会大幅高估变形。验证过逐点方向的四帧与仅有合力记录的其余帧在数据中单列。[四个逐点记录及 96 帧分离试验](axial-points.json)

**制动扭矩峰值仍有物理意义，当前差异须保留。** 在完全相同的网格和载荷下，双方分别缩小步长重新积分。表中均值按时间积分，峰值取每次仿真自身的完整输出网格。

| 步长，µs | CPU 均值，N·m | RecurDyn 均值，N·m | CPU 峰值，N·m | RecurDyn 峰值，N·m |
|---:|---:|---:|---:|---:|
| 100 | 180.11 | 179.05 | 477.35 | 258.96 |
| 50 | 179.03 | 179.57 | 258.09 | 364.41 |
| 25 | 178.95 | 177.99 | 264.65 | 475.45 |
| 12.5 | 178.34 | 177.38 | 312.31 | 513.77 |

用实际承载点的法向雅可比、共享罚刚度和三轴惯量估算，制动窗口最高局部固有频率的中位数约为 3.02 kHz。100 µs 对应每周期约 3.31 个采样点。步长敏感性和固定姿态的几何差异均已有直接证据。表中的两组峰值均未显示收敛。从这些结果可以评价平均传递载荷，瞬态齿面强度仍需独立的载荷依据。[原始步长曲线](step-refinement.png) · [重算指标](step-refinement.json) · [局部模态](contact-modes.json)

## GPU 的实测范围

新几何后端从两个完整网格各自的 AABB 树出发，筛叶对，对有限三角面进行相交检测，在设备上输出相交点、线段或共面多边形及两侧法向。两个啮合级各取 12 个实际姿态，共 3,048 对命中，逐对核对 CPU 的参考输出。RTX 3070 上交点集合的最坏双向距离为 2.71×10⁻¹⁵ m。RTX 3090 上包含交点构造的单级平均耗时分别为 236.61、407.36 µs。计时输入是预先提供的姿态，网格建树、数据上传和完整动力学求解单列。[三角形与交点比对](gpu-local.json) · [RTX 3090 几何计时](gpu-geometry-3090.json)

设备端法向求解器使用接触雅可比、有效逆质量组成的耦合矩阵和自由预测间隙。每个接触可选择隐式线性罚法、单边拉格朗日乘子或增广拉格朗日乘子。当前验证范围为无摩擦、冻结接触法向的一次求解。两接触共享一中间质量的解析问题在 RTX 3090 检查全部九种方法组合，最大冲量差 5.98×10⁻¹¹ N·s。另用三个相互耦合的接触验证 27 种组合，并测试脱开、冗余约束和不可满足的运动学约束。力学算子与三角形几何分别验证。减速器完整 GPU 闭环还缺接触区聚合、材料点与力臂更新及积分回写，尚无 5 s 实时运行结果。[九种组合的数值和时间](gpu-normal-3090.json) · [三接触独立解核对](../../../../tests/test_gpu_normal_contact.py)
