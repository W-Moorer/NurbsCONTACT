# CPU 原生 CAD 接触的受力几何与耗时

当前 `cad-occt` 在给定刚体姿态下，先排除包围盒分离的物体，再选择可能接触的局部实体，调用 OCCT 的 `BRepAlgoAPI_Common` 构造两实体的交集。每个连通重叠体贡献一处接触。作用点取体积质心，法向由两侧来源面的有向面积合成，深度取交集沿该法向的包围盒跨度。最近八个完全相同的姿态可以直接复用受力结果。上一姿态的最近面或边用于距离查询的 BVH 剪枝。Chen 2024 和 2026 选项通过步内事件接口提供候选接触时刻，固定姿态的受力几何仍走上述路径。[CAD 受力与事件实现](../../../src/cad_solid_contact.cpp) · [统一 CPU 方法入口](../../../apps/contact.cpp)

## 同一姿态下的结果

输入取自已接受的两级减速器 5 s、0.1 ms CPU 网格闭环。回放初态、0.4、0.5、0.6、0.7 ms 以及 2.5、4.6315、5 s，覆盖两级法向载荷峰值和后段工况。0.6 ms 连续查询两次以检查缓存。四个原 STEP 实体、配套的 65,732 片 Gmsh 网格、相对姿态及线性共享罚刚度在两边一一对应。采用 `mesh-obb` 加 `contour-ray` 独立重查网格。下表计时是七个不同承载姿态的单级中位数，排除了初态及重复帧，进程顺序运行，STEP 读入与写盘另计。分项占比按七次 CAD 查询的累计时间计算。[原始模型](../cpu-foundation/reducer-physics/cpu-deck.zip) · [CPU 参考运行及轨迹哈希](../cpu-foundation/reducer-physics/contact-refresh/cpu-100us.json) · [输入姿态](poses.csv) · [逐次计时、接触点及法向](profile.json)

| 固定姿态受力查询 | 原生 CAD | 网格 OBB | CAD 实体求交 | CAD 局部实体选择与准备 | CAD 区域属性提取 |
|---|---:|---:|---:|---:|---:|
| 一级直齿轮 | 1.769 s | 1.850 ms | 62.7% | 23.7% | 13.5% |
| 二级斜齿轮 | 5.234 s | 7.400 ms | 85.8% | 12.2% | 2.0% |

八个不同姿态中，两种方法给出的承载区域数在两级均相同。每级的八个新姿态都调用了一次实体间布尔求交，完全重复的第九次查询则直接命中缓存。局部选择计时包括需要时对原实体的窗口裁剪，实体求交列只计两侧所选零件之间的 `Common.Build()`。历史七步直齿轮试验启用了 CCD，最近特征复用将极值计算从 45,382 次减为 33,082 次，但两版都做了 58 次受力布尔查询，整段计时排序在两批测试中对调。本次固定姿态实验隔离了后一个成本。[直齿轮对照](../../../benchmarks/chen/README.md#reusing-the-closest-features-across-poses)

## 同一点、同一方向的穿入量

对两套算法输出的每个作用点，固定其位置和法向，用 OCCT 检查该点严格位于两个原 STEP 实体内。分别沿法向和反向查询最近的裁剪曲面交点，排除棱边或切触歧义，复核出射点外侧已离开实体，然后把两段距离相加。再沿同一直线用原模型的有限三角片独立复量。七个承载姿态提供一级 12 处、二级 21 处接触，两种种子来源各自的 33 次 CAD 核验全部成功。网格作用点上的独立网格测量复现原报深度，最大绝对差小于 0.000001 µm。半径 41 mm、球心距 81 mm 的原 STEP 双球沿球心连线另行检查，测得总穿入 1.000000 mm。

| 原始 CAD 作用点 | CAD 当前包围盒跨度 | 原 STEP 局部穿入 | 同线网格穿入 |
|---|---:|---:|---:|
| 0.5 ms，一级第一个区域 | 14.36 µm | 14.34 µm | 13.68 µm |
| 0.5 ms，二级第一个区域 | **1,085.99 µm** | **54.62 µm** | **48.55 µm** |
| 0.6 ms，二级第一个区域 | 72.62 µm | 60.76 µm | 53.17 µm |

二级在 0.5 ms 的跨度超过了模型 200 µm 的深度上限，现有罚力入口会拒绝该姿态。54.62 µm 是在同一个 CAD 质心上、沿原法向测得的局部量。包围盒上下界可以来自接触带的不同位置。此次实验没有单独测量 OCCT 包围盒相对几何投影极值的余量。

在 0.6 ms，二级两法都返回三处区域。把共享刚度 1.6 × 10⁸ N/m 乘以三处正穿入的均值，现有 CAD 跨度得到 12.234 kN。保留三个 CAD 作用点与法向，改用原 STEP 局部穿入得到 9.515 kN。使用网格给出的作用点和法向，在 STEP 上测得 8.921 kN，在网格上测得 7.265 kN。因此换用相同深度定义以后，作用点选择与几何表示仍会影响载荷。这些值是同姿态重查。已接受闭环在同一时刻保存的二级载荷为 6.964 kN，闭环迭代中还使用了预测接触点。[网格预测接触实现](../../../include/nurbscontact/predictor_regions.hpp)

## 下一步的 CPU 方法

保留当前布尔实现做小规模几何核验。在线查询优先用可复用的空间索引发现候选区域，记录两侧的原 CAD 面、裁剪边及局部参数，在相邻姿态更新实际曲面作用点、法向和局部穿入。面内跟踪离开裁剪域或靠近锐边时需要查相邻面与公共边。已有接触仍然有效时也要搜索新进入的独立承载区，避免漏掉多齿共同承载。现有 `CadContactIndex::track_interiors` 可用来试验面内跟踪，边界处理和受力区域汇总仍需开发。[现有曲面跟踪接口](../../../include/nurbscontact/cad_contact_regions.hpp)

在网格给出的作用点上，当前直接查整件 STEP 并分类的诊断程序，单个承载点中位耗时为一级 8.50 ms、二级 81.76 ms。这个计时已经给定接触点与方向。首个实现应验证限制到局部裁剪面后能节省多少时间，同时保留新承载区发现和异常回退。5 s、50,000 步且 30 min 以内完成，给两级几何、迭代和输出合计的平均预算为每主步 36 ms。闭环对照需保持原输入、积分参数和共享刚度，核对接触切换、两级载荷、轴速及输出扭矩。本次提供固定姿态证据，尚无新版独立 CAD 闭环成绩。

## 复现

准备带 OCCT 与 CPU 网格功能的 Release 构建，将运行库加入 PATH。下例的 `BIN` 指向构建出的可执行文件目录。

```bash
cmake --build build/cpu-swept --config Release --target nc_cad_distance_benchmark nc_mesh
python -m zipfile -e results/aes/cpu-foundation/reducer-physics/cpu-deck.zip build/profile-model
python benchmarks/aes/cpu_cad_region_profile.py build/profile-model/reducer-physical/common-200.scene results/aes/cpu-cad-reducer-profile/poses.csv BIN/nc_cad_distance_benchmark.exe BIN/nc_mesh.exe build/profile-repeat.json
```
