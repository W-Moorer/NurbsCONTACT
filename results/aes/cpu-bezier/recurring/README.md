# CPU 减速器的接触区力矩与候选复用验证

沿用同一两级减速器、共享线性罚刚度、预测姿态更新和 HHT 参数。两种 CAD 方法都在每个面积积分节点沿本侧材料内法向发射有限射线，按当前姿态检查另一侧最近的有效出口面。出口面属于同一个承载区时，该节点才参与合力和力矩计算。接触代表点用于识别面对和连通分组。给定相同的面对分组，面积积分只由曲面、积分规则和当前姿态决定。

两方向分别保存相对姿态邻域内可能参与检测的 CAD 参数单元和采样点编号。哈希桶用于找到历史候选表，每次使用前验证整个包围盒的平移、转动位移界以及单位法向的转动界。候选表按编号差值压缩，每方向历史预算 32 MiB，单张超预算的活动表可以单独存在。超出姿态界时重建。每次都用新姿态筛选、求交、分组并计算载荷。

## 两个独立几何对照

- **2.5371 s，二级**。固定姿态和全部积分设置，只交换原记录中相距 1.474 mm 的一个代表点。完整 STEP 参考为 140.401 N·m，修正后的两次局部结果均为 140.242 N·m。[代表点与参考值](witness-input.json)
- **4.6015 s，一级**。分别回放两条历史轨迹各自的 102 个预测姿态。最后一帧，完整 STEP 在两者上都给出两个区域，参考力矩分别为 36.725 和 36.721 N·m。常规搜索失败且估计间隙接近零时，在局部参数域继续减半搜索步幅，并重新核对两侧的实际退出面。修正后均识别出两个区域，力矩分别为 35.417 和 35.405 N·m。[姿态记录](switch-poses.npz) · [完整 STEP 参考](switch-reference.json)

这两项检验分别覆盖已发现接触区的力矩计算和浅接触区的发现。后者仍使用有限的搜索点，当前证据限于已核对的姿态。[逐项结果](fixed.json)

复核 4.6015 s 的参考值时，将 `switch-poses.npz` 中两个数组的最后一行分别送入 `nc_cad_distance_benchmark reducer-1a.step reducer-1b.step --pressure-patches 0.0004`，再按相同的共享刚度和输出轴方向换算力矩。参考文件保留了该独立程序的 SHA-256。

## 重复姿态与完整仿真

取与以往相同的八个窗口，每窗 100 个姿态，最后一窗再重复两遍。对后三个窗口各自的后 80 帧，逐帧检查候选面对数、连通分组和区域数据。另用已有完整 STEP 参考核对固定姿态力矩。三种方法的动力学长算例各自从零开始，仿真 5 s，步长 0.1 ms，单进程时限 1,800 s。[几何查询](fixed.json) · [闭环统计](closed-loop.json) · [全程曲线](reducer.png) · [原始响应](responses.npz)

### 完整减速器的响应与开销

两次跑满的结果各保留 50,001 帧，包含初始状态。表中耗时包括启动、积分和结果输出。

| CPU 接触方法 | 5 s 墙钟时间 | 对 RecurDyn 的输出轴力矩 RMS 差 | 一级、二级载荷状态切换次数 |
| --- | ---: | ---: | ---: |
| 三角网格 OBB | 294.90 s | 29.14 N·m | 1、5 |
| Bézier CAD（ours） | 1,104.14 s | 42.09 N·m | 1、5 |
| 原生 CAD | 30 min 超时，算到 3.2788 s | — | — |

两级首次承载均发生在 0.3 ms。网格输出与[前次独立运行](../mesh-obb-run.json)的响应文件 SHA-256 相同。0.5 ms 的固定姿态上，二级力矩为 534.10 N·m，完整 STEP 接触区积分为 533.53 N·m。固定姿态的局部核验与 RecurDyn 整机响应衡量不同的误差。

两级各自的重复窗口中，首次计时的 80 帧各需要建立 160 张方向候选表；两次重访各复用 160 张，重建数均为零。闭环共复用 188,409 次、重建 14,903 次，包含相邻步和较早姿态的命中。与[修正前的 Bézier 记录](../cad-bezier-run.json)相比，粗筛累计从 283.21 s 降到 81.25 s，承载区面积积分从 148.57 s 增到 459.28 s。17 个主步触发了整实体布尔求交，这些主步合计 295.34 s 墙钟时间，内核记录的实体求交累计 293.31 s。两级几何任务可并发，各环节的累计计时不能直接相加为整机墙钟时间。即使扣除这 17 步的全部时间，仍有 808.79 s。

### 原尖刺窗口的独立闭环复核

原两条 CAD 曲线在 2.5377 s 相差 −10.2656 N·m。同一减速器重新积分后，该步相差 −0.0015 N·m，2.5365 至 2.5405 s 的连续 41 步中最大绝对差为 0.0697 N·m。

到原生 CAD 的最后接受步 3.2788 s，两条 CAD 轨迹可核对力矩的 32,760 步差值 RMS 为 0.0164 N·m，最大绝对差为 0.8775 N·m，出现在 2.9649 s。输出轴速度在全部 32,789 个共同帧上的 RMS 差为 0.000187 rad/s。4.6015 s 的浅接触修复由上面的同姿态回放验证。

原生 CAD 在逐步日志中写出接受步的位置和速度，完整的载荷文件在仿真结束时写出。该算例 HHT 谱半径为零，输出轴惯量为常数。对于未细分的单步，广义力可由 `2 I (q[n] − q[n−1] − h v[n−1]) / h²` 反算。扣除相同的弹簧、阻尼与外加载荷，按轴向取符号即可得到接触力矩。用跑满的 Bézier 原始载荷逐步核验，在 49,954 个适用步上反算的最大绝对误差为 9.15×10⁻⁷ N·m。原生 CAD 的初始帧和细分步在响应文件里以 NaN 标记，局部图中这类帧留空。图的右下角显示两条 CAD 曲线的力矩差，左下角显示两条跑满曲线的 CAD 与网格力矩差。[反算和逐步核验](../../../../benchmarks/aes/cpu_recurring_contact.py)

## 复算

按[原对照的构建和场景说明](../README.md)准备 `$scene` 和 `$bin`，将以下命令从仓库根目录执行。

```powershell
$env:OMP_NUM_THREADS = "2"
python benchmarks/aes/cpu_recurring_contact.py fixed $scene "$bin/nc_cad_probes.exe"
foreach ($m in @("cad-bezier","mesh-obb","cad-patch")) {
    python benchmarks/aes/cpu_backend_run.py "$bin/nc_contact.exe" $scene "build/repeat-5s/$m" --method $m --scope contour-ray --solver penalty --penalty-stiffness shared --geometry-update predictor --spectral-radius 0
}
python benchmarks/aes/cpu_recurring_contact.py report $scene build/repeat-5s
```
