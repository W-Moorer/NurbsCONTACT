# CPU 减速器的承载区积分与局部布尔求交

本次使用原两级减速器、共享线性罚刚度、预测姿态接触更新和谱半径为零的 HHT 积分。仿真时长 5 s，步长 0.1 ms。Bézier CAD 和三角网格 OBB 使用同一个 Release 可执行文件，每种方法独立启动，单次时限 30 min。[修正前的整机记录](../recurring/README.md)

## 旧版为何在 17 个主步调用整实体求交

从旧版 50,000 步的累计布尔计数取出全部 17 个触发步，按原积分器重建两级预测姿态。每个窗口从前 9 步开始预热，再查询触发步。一级在 0.1860 s 触发一次，二级触发其余 16 次。在每一例中，曲面搜索都已发现接触，小接触区也有一条长度为 0.504 至 1.291 µm 的有效内部弦。按 12、24、48、96 格逐级积分，最后仍有一个接触区没有可用于计算压力的正厚度积分柱。旧版代码此时对整对实体重新求交。[逐姿态记录](fallback-replay.json)

只在回放中把失败区加密到每个参数方向 192 格，17 处均能算出正厚度。对三处姿态另做了独立整实体 STEP 积分，继续用同一力定律换算对应从动轴力矩。

| 姿态 | 整实体参考（N·m） | 常规格积分加失败区 192 格（N·m） |
| --- | ---: | ---: |
| 一级，0.1860 s | 73.929 | 72.669 |
| 二级，0.2741 s | 137.980 | 137.246 |
| 二级，0.9317 s | 143.071 | 140.101 |

192 格能发现窄区，三处力矩仍有 0.73 至 2.97 N·m 差异。闭环实现保留精确布尔积分作为后备。先用两个完整零件的保守几何包络限定全部可能重叠的位置，裁出包含这一区域的闭合实体，再在局部求交。重复姿态可以复用仍完整覆盖该范围的裁剪件。裁剪失败、结果有歧义或与已确认的接触矛盾时，回到完整 STEP 拓扑。

## 积分预处理

预先在零件本体坐标中存储 CAD 积分点和带面积权重的法向。为每组积分点建立定向包围盒，同时包住各条有限材料法向线段的首尾两端。运行时把该盒变换到对侧零件坐标系，用 Bézier 块的控制点包围盒和方向投影区间筛选候选。组内各积分点复用候选表，按原参数顺序检查可能的交点。保留下来的点仍在当前姿态上计算曲面出口、厚度和力臂。两级齿轮使用同一实现，预处理输入是零件几何与查询距离。

## 复算

依照[已有模型说明](../README.md)准备场景、运行库和零件预处理表，将 `NC_CAD_CACHE_DIR` 指向同一份预处理表。下列命令在仓库根目录执行，`$previous` 为修正前 Bézier 仿真的原始运行目录，`$previousProbes` 为相应版本的探测程序，`$reference` 为独立整实体求交基准程序。

```powershell
$env:OMP_NUM_THREADS = "2"
python benchmarks/aes/cpu_pressure_columns.py diagnose $scene $previous --probes "$bin/nc_cad_probes.exe" --reference $reference
foreach ($m in @("cad-bezier","mesh-obb")) {
    python benchmarks/aes/cpu_backend_run.py "$bin/nc_contact.exe" $scene "build/column-runs/$m" --method $m --scope contour-ray --solver penalty --penalty-stiffness shared --geometry-update predictor --spectral-radius 0
}
python benchmarks/aes/cpu_pressure_columns.py report $scene build/column-runs
python benchmarks/aes/cpu_pressure_columns.py paired $scene $previousProbes --probes "$bin/nc_cad_probes.exe"
python benchmarks/aes/cpu_pressure_step_replay.py $scene $previous build/column-runs/cad-bezier "$bin/nc_contact.exe" results/aes/cpu-bezier/columns/step-refinement.json
```

同姿态对照使用每级八个 100 帧窗口，每窗前 20 帧用于预热并参与几何校验，后 80 帧计时。同时记录已确认 CAD 面对及其连通分组。HHT 诊断从保存的时间、位置、速度、加速度和广义力重新推进，分别使用原主步和二分至十六分之一的子步。闭环曲线保留求解器写出的原始采样。[同姿态校验](fixed-timing.json) · [HHT 细分对照](step-refinement.json)
