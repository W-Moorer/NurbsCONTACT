# Implicit HHT-α contact experiments

The [shared STEP contact validation](../contact_validation/README.md) runs the same HHT integrator on measured optical trajectories and electrical contact pulses from three experiment families. The compiled paper includes this external comparison.

These experiments compare native CAD gap queries and dual AABB/BVH triangle queries under the same frictionless compliant law, joint constraints, force solver, and clearance acceptance test. The nominal positive clearance floor is 0.5 mm over the linear reconstruction of each accepted reduced-coordinate increment. [Numerical summary](metrics/summary.json) · [Original LaTeX paper](../../manuscript/manuscript.tex) · [Current AES manuscript](../../docs/AES/Residual-Aware-CAD-Contact.pdf)

## Reproduce

Use the [OCCT Release build instructions](../../README.md#step-queries-on-windows) and keep the same runtime PATH for the numerical run. Install the Python packages and a LaTeX distribution with LaTeXmk, pdfLaTeX, and BibTeX. Run from the repository root.

~~~powershell
python -m pip install numpy matplotlib pillow "pyvista>=0.45" av pymupdf
python benchmarks/hht/run.py build/occt/Release/nc_hht.exe results/hht
python benchmarks/assemblies/fetch.py build/assemblies
build/occt/Release/nc_assembly_bench.exe clearance build/assemblies/mmp-wheel.step benchmarks/assemblies/wheel.txt results/hht/metrics/production-wheel.csv
build/occt/Release/nc_assembly_bench.exe clearance build/assemblies/mmp-lidar.step benchmarks/assemblies/lidar.txt results/hht/metrics/production-lidar.csv
python benchmarks/hht/analyze.py results/hht
python benchmarks/hht/render.py results/hht
python benchmarks/hht/plots.py results/hht
python benchmarks/hht/paper.py results/hht --legacy
python benchmarks/hht/verify_artifacts.py results/hht build/hht-qa
~~~

Use another output directory to preserve the delivered benchmark measurements. The paper builder uses the figures in the supplied output directory. With `--legacy`, the default results build the original benchmark paper under `build/manuscript-paper`. Custom results write `paper/manuscript.pdf` under their output directory. Running the build command with the default results and without `--legacy` publishes the current AES manuscript to `docs/manuscript.pdf`. Pass `--resume` to reuse completed numerical runs, or use `--pictures-only` to render static model views. Run timed jobs serially on a machine without competing CPU loads. The complete pipeline uses the STEP pin and bore generated by the STEP round-trip test. Its location can be changed with `--trim-fixtures`.

For dynamics the STEP files are generated benchmark geometry. Each trajectory CSV contains the recorded outer-step time, native pose-level gap, peak force and generalized state. Joint coordinates are meters for translations and radians for hinges. The `solver_peak_force` column records the maximum pair force for the selected backend. Trajectory output uses one repeat. The matching `.stats.csv` contains all timing repetitions, the smallest reconstructed-step clearance, solver work, and geometry query counts. Timing includes integration, contact, and the common acceptance work. It excludes STEP import, tessellation, output, and post-run diagnostics.

The production assemblies exercise prescribed geometry sweeps and sampled clearance at the source occurrence placements. Each mesh refinement uses a fresh tessellation. The comparison uses OCCT boundary extrema as a numerical reference and records native queries that reached their task cap. Native-vs-triangle HHT runs use the STEP benchmark fixtures. Their time-step sweep uses 5, 2.5 and 1.25 ms. The guard and experimental gains have the scope detailed in the paper.
